# Política de segurança

Não publique vulnerabilidades, credenciais, dados de clientes ou consultas
sensíveis em issues públicas. Utilize o recurso de relato privado de
vulnerabilidades do GitHub quando disponível.

Inclua no relato a versão afetada, uma descrição reproduzível e o impacto
esperado. Evite anexar bancos, relatórios ou arquivos pertencentes a terceiros.
